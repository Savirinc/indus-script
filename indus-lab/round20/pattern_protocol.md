# Tamil repetition-pattern diagnostic

Fixed before computing outcomes on 2026-10-11. This tests a deliberately narrow model: one intact Indus line is one word, one sign is one phonemic segment, and the substitution is bijective within the line. It uses the frozen DravLex nonloan segmented vocabulary, not modern Tamil letter shapes or an exhaustive Old Tamil lexicon. Matching repetition patterns are necessary but not sufficient for this model; a separate mapping is implicitly permitted for every line, so matches are only an upper bound, not a consistent decipherment.

Process every raw CSV record; include only text bounded by +, containing nonzero three-digit IDs separated by hyphens or slash line boundaries. Split multiline texts; deduplicate identical lines. Include DravLex forms with Loan=false, nonempty Segments and Cognacy, remove + segment delimiters, and deduplicate words per language. Ignore concept and cognacy in matching. Compare canonical equality patterns, e.g. ABCAB=(0,1,2,0,1). Report same-length vocabulary support separately from pattern match coverage and candidate ambiguity. Report both stored and reversed order without choosing a winner. Include all 20 available Dravidian languages as related-language comparisons; these cannot establish family specificity.

For Tamil, shuffle segments independently within each word for 200 fixed seeds (20000..20199), preserving each word's length and multiset, then deduplicate. Compare coverage descriptively, with no inferential p-value, tuning or language ranking. This null addresses ordering only; it is not a historical language model. Zero candidates cannot reject Tamil because the dictionary is small and the writing-unit and word-boundary assumptions are unverified.
