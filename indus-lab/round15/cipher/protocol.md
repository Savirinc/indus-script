# Bounded synthetic hidden-alphabet benchmark

Exploratory engineering control, frozen before fitting. This does not model Indus sign values or test an Indus language hypothesis.

Take DravLex Tamil segmented forms eligible under round14: Loan=false, nonempty Segments and Cognacy. Remove '+' structural delimiter; keep every other whitespace-delimited segment atomic. Split by concept with fixed seed and an80/20 concept partition, so all synonyms of a concept stay together. Remove duplicate wordstrings within each split and remove test wordstrings identical to training wordstrings. Labels are used only by the preprocessing harness; the solver receives anonymous word token sequences without concepts, cognacy, meanings, IDs, or alignments. Preserve word boundaries and segment units.

Generate a random bijective monoalphabetic substitution with a fixed seed. Candidate output alphabet is the union of Tamil and Malayalam segment inventories: this reveals the correct target phonemic inventory as an oracle simplification. The solver never receives the encryption key or plaintext target forms. Full unaligned Malayalam wordlist is the preselected comparison; a separate same-language full Tamil wordlist is an intentionally easy positive control. Reference wordlists can contain held-out concepts and, for Tamil, the held-out target words themselves: this is known-vocabulary oracle coverage, not recovery of previously unseen lexical entries.

Optimize a fixed interpolated smoothed phoneme-trigram log likelihood fitted only to each reference wordlist. Preserve two start markers and one end marker per word. Unigram/bigram/trigram mixture weights .1/.3/.6 and add-.1 smoothing. Initialize one chain by frequency rank and five by random permutations. Six chains per reference,15000 swap proposals each; simulated annealing temperature geometrically decreases2.0 to.02. Return the highest reference-model score seen. No true-key initialization, concept matching, meaning matching, target-form objective, held-out scoring, or result-based tuning. Baselines: frequency permutation and100 random permutations (report unselected random-map accuracy distribution and highest-training-score random map). CPU target under3 minutes; terminate transparently if exceeded rather than adapt until success.

Only after all solver runs return, score recovered key on observed cipher types and held-out exact words/segments. Separately report held-out tokens whose types were seen in training. A poor positive control means this solver/objective has not established adequate recovery capability; it cannot falsify language relationship hypotheses. One encryption/split and finite restarts are not a general performance estimate. Save all fixed settings and traces.
