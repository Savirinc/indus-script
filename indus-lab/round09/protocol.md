# Frozen before model fitting: round 09
Question: Do sign inventories predict the catalogue distinction between seals and tablets across Harappa and Mohenjo-daro, beyond inscription length?
This measures associations with catalogue labels, not word meanings.
Eligible records: type beginning SEAL or TAB (three reviewed corrections applied), complete Y, at least three sign occurrences, no 000 or 999. All faces represented in text are retained. Unknown direction is allowed because features are unordered. Other object types excluded.
Duplicate protection: connect records sharing ID stem, nonmissing CISI identifier, nonmissing excavation identifier within a site, or identical unordered sign multiset. This deliberately conservative last rule can merge different objects. Drop components with conflicting target labels or multiple sites. Use one deterministic representative per remaining component. Consequently counts refer to independent analytical groups, not verified objects.
Two frozen transfers: train Harappa/test Mohenjo-daro and reverse. Each requires at least 30 groups of each class in both train and test. No parameter tuning or test-set feature selection.
Models: class-balanced logistic regression C=1 on binary sign presence plus standardized log length; comparator same regression on log length alone. Vocabulary learned from training data. Predicted probability >=0.5 is tablet. Report balanced accuracy, ROC AUC, confusion counts. Report 95% bootstrap intervals for paired balanced-accuracy gain, 2000 resamples by analytical group, fixed seed. Intervals condition on fitted models and do not capture systematic catalogue errors.
Inspection of coefficients is exploratory; label them hypotheses. A success warrants photo validation and replication on other sites; it does not establish semantic readings. A failure is a useful limit on generalization.
